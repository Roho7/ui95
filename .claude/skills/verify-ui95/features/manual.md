# Operator's manual

`/docs` is the shared manual for both libraries, in a plain paper chrome under `app/(manual)`: 1. The system, 2. Installation, 3. Sound. The old UI95 introduction lives at `/ui/about` in the Win95 chrome.

## Driving it with dither.mjs

- Run `node .claude/skills/verify-ui95/dither.mjs journey manual`. It checks the chrome, the contents, the install commands for both libraries and the package-manager switch, and saves `system.png` and `installation.png`.
