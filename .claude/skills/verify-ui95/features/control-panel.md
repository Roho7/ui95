# Control panel

Every component page is a full-viewport control panel: a stage with the live component, controls generated from its prop schema, theme and sound, and a readout. Hardware95 pages use the instrument skin; UI95 pages use the Win95 skin. Components without a panel spec fall back to their showcase examples.

## Driving it with dither.mjs

- Run `node .claude/skills/verify-ui95/dither.mjs journey control-panel`.
